# AGENTS.md

## Project Overview

This repository contains the eVitals Documentation Guide, a web-based documentation platform developed for the eVitals Remote Patient Monitoring (RPM) system. The project provides structured, searchable user documentation with role-based navigation, step-by-step guides, and screenshot support to help users efficiently navigate the platform.

## Development Guidelines

- Maintain a clean and consistent user interface.
- Keep documentation content modular and easy to update.
- Follow the existing project structure and naming conventions.
- Ensure new features remain responsive across devices.
- Test search, navigation, and routing after making changes.
- Optimize for readability, accessibility, and performance.

## Commit Guidelines

- Write clear, descriptive commit messages.
- Keep commits focused on a single feature or fix.
- Verify that the application builds successfully before pushing changes.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- JSON-based documentation content

## Purpose

The primary objective of this project is to provide an intuitive, maintainable, and scalable documentation portal that simplifies onboarding and day-to-day use of the eVitals RPM platform.
